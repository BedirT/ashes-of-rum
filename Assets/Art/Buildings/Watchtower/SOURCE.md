# Watchtower Complete

- Source archive: `Meshy_AI_Ashes_of_Rum_Watcht_0731195524_texture_fbx.zip`
- Export: `Watchtower_Complete.fbx`, one static mesh and material, 5,074 triangles.
- Runtime preparation: static import with no cameras, lights, or animation; rotated -90 degrees around X to convert the FBX up-axis to Unity Y-up, then uniformly scaled to 4.0 m tall for review.
- Material: URP Lit uses the supplied base-color and normal textures. Metallic, roughness, and emission maps are retained as source material but intentionally not enabled on this non-metal, unlit camp building.
- Status: review-only. It is not yet connected to Watchtower targeting, projectile origin, or gameplay collision.
