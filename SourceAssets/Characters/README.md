# Character Source Archive

This directory keeps only unique, reusable character inputs that are not already represented by
the integrated Archer pipeline.

- `Shared/Character_Reference_Sheet.png` is the original role reference sheet.
- `Spearman/References` contains the approved concept and orthographic model views.
- `Spearman/Meshy` contains the textured character and separate spear and shield exports needed for
  a later authored Spearman integration slice.
- `Swordsman/References` contains the available orthographic model views. No Swordsman mesh has been
  approved or preserved.

Rejected uploads, Blender autosaves, rig experiments, rendered inspection frames, duplicate Archer
downloads, and superseded archives are intentionally excluded. The accepted Archer sources remain
under `SourceAssets/Archer` and the imported runtime assets remain under `Assets/Art/Characters/Archer`.
