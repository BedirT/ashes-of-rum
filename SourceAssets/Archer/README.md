# Archer Source Package

Status: Approved source archive, Unity intake, and runtime integration.

## Visual And Equipment Contract

- Serious-but-quirky stylized foot archer with the approved chunky proportions and restrained face.
- Right-handed: left hand holds the bow and right hand draws.
- Quiver remains permanently body-worn on the character's back-left side.
- Bow and arrow remain separate models. They are never merged into the character or animation FBXs.
- Runtime integration will attach the bow to the left hand, show a temporary nocked arrow during the
  attack, hide it at release, and spawn the existing deterministic projectile.

## Contents

`References/` preserves the approved concept, bow and arrow concepts, and four A-pose generation views.

`Meshy/` preserves the original textured character export and its PBR maps. Unity production copies of
the PBR maps are under `Assets/Art/Characters/Archer/Model/Textures/`; the runtime integration builds
explicit URP materials rather than depending on Mixamo's simplified diffuse material.

The production package is under `Assets/Art/Characters/Archer/`:

- `Model/Archer.fbx`: canonical with-skin Mixamo T-pose character.
- `Animations/`: 39 normalized without-skin Mixamo motion FBXs.
- `Equipment/Bow/`: approved bow model and PBR maps.
- `Equipment/Arrow/`: approved arrow model and PBR maps.

`ANIMATION_IMPORT.json` is the machine-readable Unity importer input. Its loop list mirrors the `Yes`
rows in `ANIMATION_MANIFEST.md` and is consumed by the reusable role-generic intake command.

Rejected Meshy motions, failed Blender animation experiments, failed Mixamo uploads, and temporary
previews remain outside the repository.

## Outstanding Review Artifacts

## Verified Structure

- Character mesh: 4,262 vertices and 7,952 polygons.
- Canonical Mixamo skeleton: 49 bones.
- Skeleton fingerprint: `1df65fe6d8305b9b25de4da38cf2d5f1b89c24b054869c18a0cc8f2712f0df5e`.
- Every animation-only FBX has zero meshes and the identical 49-bone fingerprint.
- Canonical Mixamo FBX contains one embedded 2048x2048 diffuse image for portable inspection.
- Full Meshy base-color, normal, metallic, and roughness maps remain available for Unity materials.
- Unity imports the canonical model as a valid Humanoid Avatar and all 39 motion FBXs as Humanoid
  clips that copy that Avatar. Root rotation, Y, and XZ are baked into pose; only manifest-declared
  loops have loop flags enabled.
- The repeatable Unity intake marks normal maps as `NormalMap` textures and imports normal, metallic,
  and roughness maps as linear data. Base-color and emission maps retain their color semantics.

The fingerprint is SHA-256 over the sorted Blender-imported bone names, generated by
`.agents/skills/prepare-meshy-character/scripts/inspect_fbx.py`.

## Runtime Integration

`ArcherRuntimeAssetSetup` deterministically creates the runtime member prefab, Humanoid Animator
Controller, explicit URP materials, left-hand bow attachment, and normalized arrow projectile under
`Assets/Resources/Presentation/`. Runtime formation code uses those presentation assets only for Archer
members while retaining its invisible gameplay capsule, code-owned translation and facing, selection,
formation behavior, collision, navigation, attack cadence, projectile flight, damage, fog, AI, and
complete-match authority.

The runtime controller uses only `Idle`, `WalkForward`, `AimRecoil`, `HitFront`, and `DeathBackward`.
No gameplay events are animation-driven, and root motion remains disabled.
